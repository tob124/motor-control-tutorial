# 课程地图：11 周 / 44 单元

课程作者：Connor He 和 Astra。

这份地图用于排课与自查：每行是一个单元，后面是它的实验与交付物。
单元标题可以点击跳转到对应页面（在网页里）；这里是纯文本版本，便于打印。

## 第 1 周 · 电机为什么转

**转矩、反电势与机械特性** ｜ 项目：单台电机的稳态特性报告 ｜ 合计约 3 小时

| 单元 | 时长 | 实验台 | 交付物 |
|---|---|---|---|
| w1-1 从一台电机开始：转矩从哪里来 | 45 分 | 开环启动 | 一张表：本次运行的关键参数、峰值电流、稳态转速，以及你对主导因素的判断。 |
| w1-2 机械特性：一条直线的两种读法 | 45 分 | 机械特性曲线族 | 一张机械特性图 + 一段结论：不同电压下的截距与斜率分别如何变化。 |
| w1-3 拖动系统的运动方程 | 45 分 | 开环启动、速度闭环 | 一份折算计算：从机构参数算出电机轴上的等效惯量与负载转矩，并给出加速时间估算。 |
| w1-4 热与限值：连续工作还是短时冲刺 | 45 分 | 速度闭环、母线跌落 | 一张限值表：每项限值、数值、持续时间、来源与测量条件。 |

能力目标：看懂一台电机的铭牌与特性曲线，能用方程解释"为什么带上负载就掉速"。

## 工具清单

- **Python 3.12（标准库）与脚本习惯**（基础必修）— 课程的仿真内核与实验记录全部用 Python 标准库完成，不需要安装任何第三方包。
- **CAN 工具链（can-utils / python-can / candump）**（第 6–10 周）— 解析、记录与回放 CAN 报文；把总线负载率的估算与实测对上。
- **编译与调试工具链（gcc / make / gdb）**（按需（可选容器实验））— 在真实 Ubuntu 环境里编译并单步调试一个简单的电机控制程序。
- **KiCad（电气原理图与接线图）**（第 9 周按需）— 把整机电气架构画成别人能照着接线的图；交付物的一部分。
- **Docker rootless（可选的真实终端实验）**（选修）— 在隔离容器里练命令行、编译与 CAN 工具；不影响宿主机。

## 怎么用这份地图

1. 先读第 1–3 周：它们是后面所有内容的公共基础。
2. 每周至少跑一次"实验台"列里的实验；只看讲解不跑实验，学不到手上的判断力。
3. 每周结束检查"交付物"列：写不出来就说明还没真正掌握。
4. 第 11 周的综合项目会用到前 10 周的全部交付物。
