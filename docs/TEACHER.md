# 教师 / 队长使用说明

课程作者：Connor He 和 Astra。

这门课的目标不是让新队员"会调一个电机"，而是让他**能独立设计一台 ROBOCON 机器人的电控系统**：
从看懂电机特性，到设计闭环、通信、整机供电与安全链，最后交出一份别人能复现的设计方案。

## 一、先跑起来

在项目目录执行：

```bash
./start.sh              # 默认 http://127.0.0.1:8770/
./start.sh --check      # 只自检，不启动
```

不需要 pip、不需要虚拟环境、不需要联网、不需要 Docker。课程服务只用 Python 标准库。

自检与验收命令：

```bash
python3 -m unittest discover -s tests      # 物理 + 接口 + 内容一致性
python3 scripts/build_content.py --check   # 内容结构校验（改过文本后必跑）
```

## 二、课程结构（11 周 / 44 单元）

| 周 | 主题 | 学员应该能做的事 |
|---|---|---|
| 1 | 电机为什么转 | 写出电枢与机械方程，解释机械特性的斜率与截距 |
| 2 | 三相与坐标变换 | 手算 Clarke/Park，说明为什么 dq 量是直流 |
| 3 | 功率器件与 PWM | 算伏秒平衡，说明 SVPWM 的 15.5% 优势从哪来 |
| 4 | FOC 与电流环 | 整定电流环，解释采样周期为什么限制带宽 |
| 5 | 速度环、位置环与反馈 | 判断"转不准"是控制、反馈还是机械问题 |
| 6 | 通信与实时性 | 设计报文表并算出总线负载与抖动 |
| 7 | 运动学与机构 | 从电机转速算到轮端位移与机构行程 |
| 8 | 轨迹跟踪与协调 | 让底盘走规定路径并量化误差 |
| 9 | 整机系统设计 | 做电源预算、安全链与状态机 |
| 10 | 联调与排障 | 按故障树定位"不动、乱动、烧了" |
| 11 | 综合项目 | 交出完整的 RoboCON 电控设计包 |

每周 4 个单元，建议按每周 6–8 小时安排：讲解与实验约 3–4 小时，独立任务与复盘 3–4 小时。

## 三、课堂建议

**先演示，再讲公式。** 每节课开头花 5 分钟在实验台跑一次对应实验，让大家先看到现象
（例如"电压不变，负载加大后转速掉下来"），再回到方程解释为什么。
直接讲方程会失去大部分听众。

**用故障注入做诊断训练。** 第 5、10 周有 `encoder_reversed`、`phase_swap`、`vbus_sag`、
`mechanical_jam` 等故障开关。建议让学员先看曲线猜原因，再对照"签名"。
课程明确不伪造数据：故障只作用于反馈与执行通道，物理状态仍由真实模型推进。

**要求学生保存参数快照。** 任何结论都必须附参数与实验条件。
没有参数的曲线，两周后连作者自己都解释不了。

**允许"调不出来"。** 电流环在控制周期 1 ms 下有稳定的增益上限（约 200 rad/s 带宽）。
把 Kp 调到 2000 以上会振荡，这不是错误，而是课程第 4 周的核心结论之一。
让学员自己找到那条边界，比背一个数字有用得多。

## 四、评价量表（建议）

| 维度 | 权重 | 观察点 |
|---|---|---|
| 物理正确性 | 40% | 结论能用方程或数据支撑；单位与坐标约定一致 |
| 可复现性 | 25% | 参数、工况、数据齐全；别人能重跑出同样的曲线 |
| 排障证据 | 20% | 有"现象 → 假设 → 验证"的链条，而不是试参数 |
| 技术表达 | 15% | 图纸/框图完整；能向非本方向同学讲清取舍 |

第 11 周的设计包按这四个维度评审。系统会导出《学习与作品记录》Markdown，
但那只是自评材料，**不等于教师认证**。

## 五、常见提问与回答

**问：没有硬件怎么学电控？**
答：本课程的闭环、调制与整机实验都在数值模型上完成，模型有解析解对照与自动测试。
硬件操作的差异主要在接线、EMC 与散热经验上，这些在第 9–10 周以检查清单与故障树的方式覆盖。
真机训练仍不可替代，建议在有条件时按课程的检查清单做实机对照。

**问：学员基础不同怎么办？**
答：第 1–3 周是共同基础。已经会 FOC 的学员可以跳过第 1 周实验，但建议至少做一次
第 3 周的伏秒平衡手算——那是很多人"以为自己会"的地方。

**问：为什么有些曲线看起来不完美？**
答：模型是平均值模型，不含齿槽转矩、铁损与死区补偿；热模型是一阶集总参数。
课程的立场是**如实标注边界**，而不是把曲线修得好看。详细边界见 `docs/MOTOR_MODEL.md`。

**问：如何把课程接到实机？**
答：第 9 周的电源预算与安全链清单可以直接用于实机设计评审；
第 10 周的故障树对应真实调试流程。实机接线前请务必完成安全链检查表。

## 六、维护者提示

- 内容源在 `scripts/content_part1.py` … `content_part4.py`，改完运行
  `python3 scripts/build_content.py`（服务按文件修改时间重新加载，不必重启）。
- 物理模型在 `server/sim/`，每个模块都有对应的自动测试。**改动物理后必须跑测试**，
  如果测试失败而你认为测试过时了，请先写下为什么。
- 接口与前端在 `server/httpd.py`、`server/app.py`、`dist/`。
  前端没有构建步骤：改完刷新页面即可。
- `dist/vendor/` 里的 xterm.js 是第三方组件，保留了原始许可证与来源清单，请勿删除。
